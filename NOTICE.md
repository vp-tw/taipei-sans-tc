## Taipei Sans TC font software

`packages/core/src` and the generated font files under `packages/core/dist`
contain Taipei Sans TC font software. They follow the original author's
[SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).

- Original font information: [JT Foundry](https://sites.google.com/view/jtfoundry/zh-tw)
- Licensing information: [JT Foundry downloads](https://sites.google.com/view/jtfoundry/zh-tw/downloads)
- Upstream basis: Source Han Sans, as stated by JT Foundry

This repository is an unofficial webfont package and is not affiliated with,
endorsed by, or maintained by JT Foundry.
